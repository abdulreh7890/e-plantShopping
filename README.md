# Paradise Nursery Shopping Application

Paradise Nursery is a React and Redux-based plant shopping application developed as part of the final project.

The application allows users to browse a collection of houseplants organized into different categories, add plants to a shopping cart, manage product quantities, remove products, and view the total cart cost.

## Features

- Paradise Nursery landing page
- Company information
- Product listing with multiple plant categories
- Plant images, names, descriptions, and prices
- Add to Cart functionality
- Dynamic shopping cart quantity
- Increase and decrease product quantities
- Remove products from the cart
- Individual product total calculation
- Overall cart total calculation
- Continue Shopping functionality
- Checkout button with "Coming Soon" message
- Redux state management
- Responsive user interface

## Technologies Used

- React Redux
